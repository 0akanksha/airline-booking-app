# Aerion — Airline Booking App

Full-stack flight search & booking demo: React + Vite + Tailwind frontend, Express + Neon Postgres backend, Stripe Checkout payments, admin dashboard — all served from a single process/port.

## Stack

- **Frontend**: React + Vite, Tailwind CSS v4, React Router
- **Backend**: Express (in `server/`), same process/port as the frontend
- **Database**: Neon serverless Postgres via Drizzle ORM
- **Auth**: JWT httpOnly cookie, bcrypt — admin-only accounts (passenger booking is guest, no signup)
- **Payments**: Stripe Checkout Sessions (test mode)

## Local development

```bash
npm install
npm install --prefix server
cp server/.env.example server/.env   # fill in DATABASE_URL, JWT_SECRET, ADMIN_EMAIL/PASSWORD, Stripe keys
npm run db:push --prefix server      # push schema to Neon
npm run db:seed --prefix server      # seed sample flights
npm run dev                          # http://localhost:4000 by default
```

For Stripe webhooks locally, run in a second terminal:

```bash
stripe listen --forward-to localhost:4000/api/webhooks/stripe
```

Copy the `whsec_...` it prints into `server/.env` as `STRIPE_WEBHOOK_SECRET`.

## Admin

No public signup — the admin account is seeded from `ADMIN_EMAIL`/`ADMIN_PASSWORD` in `server/.env` on first server start. Sign in at `/admin/login`.

## Deploy (Render)

Single Web Service, defined in `render.yaml`:

- **Build**: `npm run build:all`
- **Start**: `npm start`
- **Health check**: `/api/health`

Required env vars (set in the Render dashboard, not committed):

| Var | Notes |
|---|---|
| `DATABASE_URL` | Neon pooled connection string |
| `JWT_SECRET` | auto-generated by Render |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | seeds the initial admin user |
| `STRIPE_SECRET_KEY` / `STRIPE_PUBLISHABLE_KEY` | test-mode keys |
| `STRIPE_WEBHOOK_SECRET` | from the **production** webhook endpoint in the Stripe Dashboard — this is a different value from the local `stripe listen` secret |

`NODE_ENV` is intentionally **not** set as a platform env var — it's set to `production` only inside `server/package.json`'s `start` script. Setting it at the platform level makes `npm install` skip devDependencies during the build step, which breaks `vite build`/`tsc`.

After deploying, add a webhook endpoint in the Stripe Dashboard pointing at `https://<your-render-url>/api/webhooks/stripe` for the `checkout.session.completed` event, then copy its signing secret into `STRIPE_WEBHOOK_SECRET`.
